# CloakBrowser 开关设计

> 日期：2026-07-19
> 状态：已确认
> 范围：`packages/engine/` — Browser Context 工厂 + CloakBrowser 可选启用

---

## 1. 目标

提供统一的 CloakBrowser（反检测浏览器）开关机制：
- **环境变量** `CLOAK_ENABLED` 全局控制（默认关闭）
- **Pipeline config** 可单独覆盖
- 对 Playwright 原生和 browser-use 两种执行模式透明生效

---

## 2. 配置优先级

```
Pipeline config["cloak_enabled"] > 环境变量 CLOAK_BROWSER_ENABLE > 默认 False
```

| 层级 | 配置方式 | 值 |
|------|----------|---|
| 环境变量 | `CLOAK_BROWSER_ENABLE=1` 或 `CLOAK_BROWSER_ENABLE=true` | 全局默认 |
| Pipeline config | `{"cloak_enabled": true}` 或 `{"cloak_enabled": false}` | 覆盖全局 |
| 缺省 | 未设置任何配置 | `False`（标准 Playwright） |

---

## 3. 环境变量规范

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `CLOAK_BROWSER_ENABLE` | bool-like string | `"0"` | `"1"` / `"true"` / `"yes"` = 启用 CloakBrowser |

放在 `.env` 或 Docker Compose environment 中，后端启动时读取。命名遵循项目统一前缀规范（`BROWSER_` 为浏览器引擎模块前缀）。

## 4. 核心接口：Browser Context Factory

```python
# packages/engine/src/engine/browser_factory.py

import os
from playwright.async_api import async_playwright, BrowserContext

def resolve_cloak_enabled(pipeline_config: dict) -> bool:
    """解析 CloakBrowser 开关，优先级：config > env > default."""
    # 1. Pipeline config 覆盖
    config_val = pipeline_config.get("cloak_enabled")
    if config_val is not None:
        return bool(config_val)
    # 2. 环境变量
    env_val = os.environ.get("CLOAK_BROWSER_ENABLE", "").strip().lower()
    return env_val in ("1", "true", "yes", "on")


async def create_browser_context(
    pipeline_config: dict,
    **context_kwargs,
) -> tuple["Browser", BrowserContext]:
    """创建浏览器 context。

    无论 CloakBrowser 是否启用，返回标准 Playwright BrowserContext。
    调用方使用相同的 page API，业务代码零改动。
    """
    headless = pipeline_config.get("headless", True)
    use_cloak = resolve_cloak_enabled(pipeline_config)

    if use_cloak:
        from cloakbrowser import CloakBrowser
        browser = await CloakBrowser.launch(headless=headless)
        context = await browser.new_context(**context_kwargs)
    else:
        pw = await async_playwright().start()
        browser = await pw.chromium.launch(headless=headless)
        context = await browser.new_context(**context_kwargs)

    return browser, context
```

## 5. 与三种执行模式的集成

### 5.1 Playwright 原生（Pipeline 直接用）

```python
class OaTodosPipeline(BasePipeline):
    async def execute(self, config, logger):
        browser, context = await create_browser_context(config)
        try:
            page = await context.new_page()
            await page.goto(config["login_url"])
            # ... 标准 Playwright API
        finally:
            await context.close()
            await browser.close()
```

### 5.2 browser-use 集成

```python
from browser_use import Agent

class AiBrowsePipeline(BasePipeline):
    async def execute(self, config, logger):
        browser, context = await create_browser_context(config)
        try:
            # browser-use 接受自定义 context
            agent = Agent(browser_context=context, ...)
            await agent.run(task=config["task_prompt"])
        finally:
            await context.close()
            await browser.close()
```

### 5.3 效果

| `cloak_enabled` | Playwright 流程 | browser-use 流程 |
|---|---|---|
| `false`（默认） | 标准 Chromium | 标准 Chromium + AI |
| `true` | CloakBrowser（反检测）| CloakBrowser + AI |

业务代码（`page.goto`、`page.click` 等）完全不变。

## 6. 内网 vs 外网场景指引

| 场景 | 推荐配置 | 理由 |
|------|----------|------|
| 内网 OA（ioa.sd-port.net）| `cloak_enabled: false` | 内网无反检测，标准浏览器即可 |
| 外部平台（有 Cloudflare）| `cloak_enabled: true` | 需要指纹伪装 |
| 混合部署 | 环境变量关，特定 Pipeline config 开 | 按需启用 |

---

## 7. 约束

- CloakBrowser 为可选依赖 — 未安装时 `cloak_enabled: true` 应 raise 明确错误
- 不改变 Pipeline 业务逻辑 — 开关只影响浏览器实例的创建方式
- Context 生命周期由 Pipeline 管理（`try/finally` 确保关闭）
- 环境变量在 backend `Settings`（Pydantic Settings）中声明，与其他配置统一管理
